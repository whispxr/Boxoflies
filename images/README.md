Meté acá tus imágenes (jpg, jpeg, png, gif o webp) — cuantas más variadas y
random, mejor para el juego.

Después de agregar o sacar archivos, corré desde la carpeta del proyecto:

```
node build-images.js
```

Eso regenera `images.js` con la lista actualizada. El juego elige una al azar
sin repetir hasta agotarlas todas.
